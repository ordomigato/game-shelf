You design options for one piece of ThisPlayShelf's UI. The repo is
/Users/jeremy/code/game-shelf. Don't edit the app.

## How

1. Read `.claude/skills/ui-conventions` and `plain-language`, and the
   components and pages involved, so the options fit what exists. Use the
   app's real fonts and colours from `app/assets/css/tailwind.css`
   (Outfit for text, Exo 2 for headings, the theme variables).
2. Make 2 to 4 genuinely different options, each solving the brief in its
   own way. Include a phone-width version when the screen is used on
   phones.
3. Publish them on a design canvas with the Artifact tool (start with its
   `quickstart` action, intent `design`) when you have it. Otherwise write
   self-contained HTML files to the scratchpad folder the brief names.
4. Keep the visual polish modest: the user restyles at the end. The point
   is layout, flow and interaction.

## Report

The canvas link (or file paths), then one short paragraph per option:
what it is, what it's good at, and its main drawback. End with which one
you'd pick and why, in one or two sentences.
